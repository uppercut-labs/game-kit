; Bitmap fonts: the single source of truth for the glyph tables in this package.
;
; A line starting with ; is a comment (to the end of the line). A font is
;   font <width>x<height> advance <pixels>
; followed by glyphs, each
;   glyph <character code, decimal or 0x hex>
; and then <height> lines of <width> characters: # is an inked pixel, . is empty.
; Codes may come in any order and each appears once. The generator (tools/gen_bitmap_font.py)
; writes the C header, the Python table and the standalone arrays from this file.

; 5x7: 67 glyphs, ASCII 32-126 apart from lowercase and braces. Lowercase draws as capitals.
